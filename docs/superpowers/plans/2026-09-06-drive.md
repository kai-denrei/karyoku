# Drive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Drive the MKCX-2 onto a generated plate through a proximity gate past sentries that sweep limited arcs and fire tracers, with a hit counter.

**Architecture:** `src/drive.js` is the pure simulation (hull, gates, sentries, tracers, line of sight) tested in Node. `src/plate-scene.js` is the shared three.js builder extracted from `plate-tab.js`. `src/drive-tab.js` wires input, camera, models and HUD around both.

**Tech Stack:** as the plate generator plan. Spec: `docs/superpowers/specs/2026-09-06-drive-design.md`.

## Global Constraints

Same as `2026-09-06-plate-generator.md`: no build step, `?v=` tokens via `bust.sh`, no emoji, no `Math.random` in logic, pure modules never import three.js, north is -Z, `rotation.y = -rot * PI/2` for pieces and `PI - heading` for anything whose authored forward is +Z.
